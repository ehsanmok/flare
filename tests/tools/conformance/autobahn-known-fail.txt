# Autobahn cases that are expected to report something other than OK
# or NON-STRICT, one case id per line. The gate in
# tests/tools/run_conformance.sh fails on any case outside this list,
# so the question it answers is "no new failures", not "no failures" --
# the same posture as h2spec-known-fail.txt.
#
# Measured on 2026-09-20, the first run of this suite against flare
# (CI run 35521608297, commit 8a62187). 63 of roughly 450 cases. They
# are not noise and they are not the fixture's fault: the echo server
# under test is an ordinary use of the public API.
#
# Every entry below has a reason, and the reasons reduce to three
# gaps in flare.ws's server side. Fixing them is 0.12 work tracked in
# the "Known gaps" section of docs/features.md; each fix should delete
# its block from this file.
#
# Sections 12 and 13, permessage-deflate, are excluded in
# autobahn.json rather than listed here -- the standalone WsServer
# handshake does not negotiate the extension, so those cases would be
# measuring the fixture. See autobahn-README.md.
